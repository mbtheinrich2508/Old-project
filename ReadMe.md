# Stacks and Queues

## Instructions

Step 1: Install the latest version of Python from [here](https://www.python.org/downloads/).

Step 2: Install a virtual environment using the following command:

```bash
pip install virtualenv
```

Step 3: Create a virtual environment using the following command:

```bash
virtualenv venv
```

Step 4: Activate the virtual environment using the following command:

```bash
# For Windows
venv\Scripts\activate
# For MacOS/Linux
source venv/bin/activate
```

Step 5: Run the script using the following command:

```bash
# Example 1
python ListStack.py < tinyTale.txt
```
```bash
# Example 2
python Evaluate.py                  # Type this command and press enter
( 1 + ( ( 2 + 3 ) * ( 4 * 5 ) ) )   # Type/copy this expression and press enter
```
